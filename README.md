# Проект спринта 7: Яндекс.Самокат

## Описание проекта

**Яндекс.Самокат** — это сервис, позволяющий арендовать самокаты.

В рамках проекта необходимо покрыть автотестами следующий функционал API Яндекс.Самоката:

### **Создание курьера**

- курьера можно создать;
- нельзя создать двух одинаковых курьеров;
- чтобы создать курьера, нужно передать в ручку все обязательные поля;
- запрос возвращает правильный код ответа;
- успешный запрос возвращает `{"ok":true}`;
- если одного из полей нет, запрос возвращает ошибку;
- если создать пользователя с логином, который уже есть, возвращается ошибка.

### **Логин курьера**

- курьер может авторизоваться;
- для авторизации нужно передать все обязательные поля;
- система вернёт ошибку, если неправильно указать логин или пароль;
- если какого-то поля нет, запрос возвращает ошибку;
- если авторизоваться под несуществующим пользователем, запрос возвращает ошибку;
- успешный запрос возвращает `id`.

### **Создание заказа**

#### **При создании заказа**

- можно указать один из цветов — BLACK или GREY;
- можно указать оба цвета;
- можно совсем не указывать цвет;
- тело ответа содержит `track`.

### **Список заказов**

В тело ответа возвращается список заказов.

Автотесты по описанным выше сценариям выполнены с использованием **Pytest**, **Requests** и **Allure**.

### Структура проекта

- `allure-results` - Allure-отчет
- `tests` - тесты
- `conftest.py` - фикстуры
- `data.py` - тестовые данные
- `endpoints.py` - эндпоинты
- `methods.py` - методы для запросов
- `status_codes.py` - коды состояния HTTP

### Запуск автотестов

#### **Запуск автотестов с созданием отчета о тестировании в Allure**

 `pytest ./tests --alluredir=./allure-results`

#### **Формирование отчета в Allure**

 `allure serve ./allure-results`
